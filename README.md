# CreateFixes

CreateFixes is a server side Forge mod for Minecraft 1.20.1 that reduces known Create 6.x performance hotspots.

## Development

Use Java 17 and the checked in Gradle Wrapper.

```powershell
.\gradlew.bat build
```

```bash
./gradlew build
```

See [the documentation index](docs/README.md) for architecture and verification details.
